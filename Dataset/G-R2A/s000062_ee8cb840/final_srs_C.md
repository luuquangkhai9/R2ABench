# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 定义了由 Udacity 自动驾驶汽车工程师毕业项目系统集成项目所代表的仓库组件的、以证据为支撑的需求。它重点关注启动、仿真执行、路径点跟随、速度遵循，以及由仓库证据支持的真实世界测试工作流。来源：`E001`、`E002`。

### 产品范围
该产品是一个自动驾驶汽车项目提交物，旨在通过提供的启动文件在仿真器模式和站点模式下运行，在仿真器中平滑地跟随路径点，遵守路径点定义的目标速度，并通过录制的训练 bag 和交通灯检测验证支持真实世界测试。来源：`E001`、`E002`。

### 目标读者
本文档面向在仿真器模式或站点模式下构建、启动、测试或评估该仓库的评估人员、开发人员和操作人员。来源：`E001`、`E002`。

## 2. 总体描述

### 产品视角
该仓库提供了一个围绕基于 ROS 的毕业项目环境的项目工作流，该环境可通过预定义的启动文件启动，并通过 Udacity 仿真器或录制的真实世界 bag 回放进行运行。文档化的设置使用 Docker 和 ROS 作为执行依赖项。来源：`E001`、`E002`。

### 产品功能概述
- 使用仓库提供的启动文件在仿真器模式和车辆/站点模式下启动系统。`E001`
- 在仿真器中平滑地跟随路径点。`E001`
- 遵守路径点 `twist.twist.linear.x` 值中携带的目标最高速度。`E001`
- 在 ROS 启动后支持仿真器执行。`E002`
- 支持使用已下载并解压的训练 bag 在站点模式下进行回放式真实世界测试。`E002`
- 在站点模式测试期间对真实图像上的交通灯检测进行验证。`E002`

### 用户类别
- `Evaluator`：运行提供的启动文件，以在仿真器模式和站点模式下测试提交物。`E001`
- `Developer/Operator`：构建 Docker，启动 ROS，运行仿真器，并执行基于 bag 的真实世界测试。`E002`

### 运行环境
- 用于项目构建和执行的 Docker 环境。`E002`
- 容器内的 ROS 环境。`E002`
- 用于基于仿真器执行的 Udacity Capstone Project Simulator。`E002`
- 使用录制训练 bag 进行真实世界测试回放的站点模式。`E002`

### 假设与依赖
- 在构建和运行项目容器之前，必须已安装 Docker。`E002`
- 在进行仿真器测试之前，必须已下载、解压并使 Udacity 仿真器可运行。`E002`
- 真实世界测试依赖于录制训练 bag 的可用性以及 bag 回放工具。`E002`
- 评估使用 `launch/styx.launch` 进行仿真器测试，使用 `launch/site.launch` 进行车辆/站点测试。`E001`
