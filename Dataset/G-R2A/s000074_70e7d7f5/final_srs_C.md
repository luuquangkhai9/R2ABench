# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 规定了 `OAID/Tengine` 在提交 `2375c98f6ad2cd45d65364efe5ac7538425da7d5` 时基于证据的需求，重点关注已文档化的示例工作流、公开的 API、模型序列化/转换行为，以及支持的构建/部署特性。

### 产品范围
有证据表明，Tengine Lite 是一款面向推理的软件产品，提供：
- 用于分类、检测、分割、姿态估计、关键点检测和字符识别任务的示例应用程序。
- 面向 C、C++ 和 Python 的 API 接口。
- 用于解码二进制 `tmfile` 模型数据的序列化器。
- 模型转换工具，包括 Linux 预编译工具和基于 WebAssembly 的浏览器本地在线转换器。
- 基于 CMake 的快速跨平台编译。

### 目标读者
本文档适用于：
- 通过 C、C++ 或 Python API 集成 Tengine Lite 的开发者。
- 运行所提供示例应用程序的用户。
- 验证仓库所支持产品行为的评估人员。

### 参考资料
- 仓库：`OAID/Tengine`
- 提交：`2375c98f6ad2cd45d65364efe5ac7538425da7d5`
- 证据来源：`E001` 到 `E006`

## 2. 总体描述

### 产品视角
仓库证据将 Tengine Lite 呈现为一个包含示例应用程序、API 文档、用于 `tmfile` 模型解码的序列化器以及模型转换实用工具的库/工具包。示例展示了使用提供的模型和图像执行常见神经网络任务的端到端流程。来源：`E001`、`E005`、`E006`。

### 产品功能概述
- 为多种 AI 视觉和 OCR 任务提供可运行示例。`E001`, `E002`, `E006`
- 支持通过与原始 Tengine 兼容的 C API 使用。`E001`, `E006`
- 提供 C++ API 文档。`E003`
- 提供 Python API 文档。`E004`
- 通过序列化器模块解码二进制 `tmfile` 模型格式。`E005`
- 在 Linux 上以及通过浏览器本地在线转换器提供模型转换工具。`E005`

### 用户类别
- 在原生应用程序中使用 Tengine Lite 的 C API 集成人员。`E001`, `E006`
- C++ API 用户。`E003`
- Python API 用户。`E004`
- 使用所提供模型和图像验证支持任务的示例用户。`E001`, `E002`, `E006`

### 运行环境
- 使用 CMake 进行编译的跨平台构建环境。`E005`
- 用于预编译模型转换工具的 Linux 环境。`E005`
- 支持 WebAssembly 的 Web 浏览器环境，用于在线模型转换工具。`E005`

### 假设与依赖
- 示例执行依赖于在运行示例之前将图像和模型放置在项目根目录下。`E002`
- 模型转换可用性依赖于 Linux 预构建工具或能够执行本地 WebAssembly 的浏览器。`E005`

## 3. 外部接口需求

| 接口领域 | 需求摘要 | 来源证据 |
|---|---|---|

| 软件/API 接口 | 产品应公开与原始 Tengine 使用模式兼容的 C API，以及已文档化的 C++ 和 Python API。 | `E001`, `E003`, `E004`, `E006` |
| 通信接口 | 证据中未直接规定网络通信接口。在线模型转换器基于浏览器并在本地执行转换。 | `E005` |
| 数据交换格式 | 序列化器应将二进制 `tmfile` 模型格式解码为序列化模型参数。示例工作流使用模型文件和图像输入。 | `E002`, `E005` |
