# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 基于所提供的仓库证据包，仅针对 `bcgov/embc-ess` 仓库在提交 `19d9e1c803e5ba2a7fed5ca53f8a44c16d717d25` 时受支持的组件，定义有证据支撑的需求。

### 产品范围
证据支持一个 Web 前端应用程序，该应用：
- 在 Web 浏览器中运行，
- 使用后端 API，
- 应用基于角色的路由以及登录/会话处理，
- 针对多个业务端点执行 HTTP 操作，
- 对选定的共享数据使用客户端存储，
- 并包含用于管理 MS SQL 数据库中数据的 SQL 脚本。

## 2. 总体描述

### 产品视角
该产品是一个基于浏览器的前端，运行依赖 API，并集成了基于角色的访问控制和会话处理。它还包含用于 MS SQL 数据库维护的 SQL 脚本。前端对选定的客户端状态使用 NgRx store。来源：`E001`, `E004`, `E005`, `E006`。

### 产品功能概述
仓库中有证据支持的功能包括：
- 将用户引导到适合其角色的路由，
- 将未认证用户重定向到登录页，
- 根据用户角色检查路由访问权限，
- 在 API 返回未授权响应后注销用户并显示会话过期页面，
- 在 HTTP 请求时重置 watchdog 计时器，
- 在初始化时加载变化不频繁的受控列表数据，
- 对 evacuee、incident-task、organization、referral 和 registration 服务执行端点操作，
- 对用户通知进行排队和显示，
- 通过仓库 SQL 脚本管理选定的 MS SQL 数据。  
来源：`E003`, `E004`, `E005`, `E006`。

### 用户类别
| 用户类别 | 描述 | 来源 |
|---|---|---|
| 基于角色的前端用户 | 其落地路由和路由访问依赖于分配角色的用户 | `E001`, `E004` |
| 已登录用户 | 拥有活动应用会话、受未授权/会话过期处理约束的用户 | `E004` |
| 开发人员 | 在指定开发环境中使用代理和与角色配对的令牌在本地运行前端的用户 | `E001` |
| 数据库操作员/管理员 | 针对 MS SQL 数据库执行仓库 SQL 脚本的用户 | `E006` |

### 运行环境
| 方面 | 需求支持的环境 | 来源 |
|---|---|---|
| 客户端运行时 | Web 浏览器 | `E001` |
| 后端依赖 | 前端所需的 API | `E001` |
| 本地开发 | 使用代理和令牌的指定开发环境 | `E001` |
| 数据库 | 用于仓库 SQL 脚本的 MS SQL Database | `E006` |

### 假设与依赖
- 前端需要使用一个 API。`E001`
- 开发访问依赖代理和三个与角色配对的令牌。`E001`
- 应用必须遵循 SiteMinder，其中仅后端开发后门仅在特定指定的开发环境中启用。`E001`
- SQL 维护脚本依赖对目标 MS SQL 数据库的访问。`E006`

## 3. 外部接口需求

### 用户界面
| 接口 | 需求支持的行为 | 来源 |
|---|---|---|
| 落地页路由 | 用户被引导到适合其角色的正确路由 | `E004` |
| 登录/会话处理 | 未认证用户被重定向到登录页；会话过期会转到会话过期页面 | `E004` |
| 通知 | notifier 组件可以观察已排队的通知并将其显示给用户 | `E003` |

### 软件/API 接口
| 接口 | 支持的操作 | 来源 |
|---|---|---|
| `evacuee` 端点 | HTTP 服务使用参数执行读取操作 | `E003` |
| `incident-task` 端点 | HTTP 服务使用参数执行创建、读取和更新操作 | `E003` |
| `organization` 端点 | HTTP 服务使用参数执行创建、读取和更新操作 | `E003` |
| `referral` 端点 | HTTP 服务使用参数执行创建、读取、更新和删除操作 | `E003` |
| `registration` 端点 | HTTP 服务使用参数执行创建、读取和更新操作 | `E003` |
| `controlled-list` 端点/数据源 | 在初始化时加载变化不频繁的数据到客户端 store 中 | `E003` |

### 通信接口
| 接口 | 支持的行为 | 来源 |
|---|---|---|
| 客户端 HTTP 请求 | 请求受未授权响应处理和 watchdog 计时器重置约束 | `E004` |
| 本地开发 API 访问 | 使用代理和令牌；开发绕过仅限后端并受环境限制 | `E001` |

### 数据交换格式
支持性证据表明存在带参数的 HTTP 端点使用以及 registration 服务中的 PDF 收集，但证据包中未定义载荷模式或消息格式。来源：`E003`。

| FR-004 | HTTP 活动时重置 watchdog | 发起任意客户端 HTTP 请求 | 系统应在每次 HTTP 请求时重置 watchdog 计时器 | watchdog 计时器被刷新 | 中 | 测试 | `E004` |
| FR-005 | 受控列表初始化加载 | 应用初始化 | 系统应在初始化时加载变化不频繁的受控列表数据，并将其放入 NgRx store 中 | 受控列表数据在客户端状态中可用 | 中 | 测试 | `E003`, `E005` |
| FR-006 | 端点操作支持 | 客户端请求对受支持业务端点执行操作 | 系统应支持：对 `evacuee` 执行读取；对 `incident-task`、`organization` 和 `registration` 执行创建/读取/更新；以及对 `referral` 执行创建/读取/更新/删除，并使用端点参数 | 所请求的端点操作被发送到相应 API | 高 | 测试 | `E003` |
