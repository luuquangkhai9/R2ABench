# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 基于所提供的仓库证据，仅针对提交 `2677633e86fa623224308bf35c4a3153c95c0030` 的 `de1ux/statlord` 定义仓库特定的软件需求。

### 产品范围
`statlord` 旨在于备用 OLED、电子纸、LCD 和浏览器上显示实时数据。它包括：
- 一个基于浏览器的编辑器，用于跨显示设备创建布局，
- 一个用于提交数据和注册显示设备的 API，
- 一个查看器层，被描述为渲染各显示设备视图的无头浏览器。  
来源：[E002]

### 目标读者
- 维护者和贡献者
- 测试人员和评审人员
- 使用 API 或浏览器编辑器的集成人员
- 部署该技术栈的运维人员

## 2. 总体描述

### 产品视角
该产品是一个基于 Web 的系统，包含：
- 一个使用 Node.js/npm 构建并部署为静态资源的客户端/编辑器，
- 一个公开由 API 支持的数据实体的 Python 服务器，
- 一个被描述为渲染显示输出的无头浏览器的查看器组件。  
来源：[E001], [E002], [E005], [E006]

### 产品功能概述
- 接受提交到 API 的数据以供显示设备使用。[E002]
- 允许以唯一名称和分辨率注册显示设备。[E002]
- 允许为不同显示设备创建布局。[E002]
- 支持在多个显示设备上定位文本、仪表和其他数据。[E002]
- 通过查看器实例渲染每个显示设备“看到”的内容。[E002]

### 用户类别
- 创建和配置布局的浏览器编辑器用户。[E002]
- 提交数据和注册显示设备的 API 客户端。[E002]
- 在本地或容器化环境中运行该技术栈的运维人员/开发人员。[E001], [E002]

### 运行环境
- 开发依赖：PostgreSQL、Python `>3.5`、Node.js、npm。[E002]
- 容器化构建/运行时证据：`python:3.7`、Node.js、curl、Python 包安装、静态客户端构建、Django 开发服务器启动。[E001]
- 编辑器工作流需要浏览器访问。[E002]

### 假设和依赖
- PostgreSQL 是开发所必需的依赖项。[E002]
- 客户端构建依赖 Node.js 和 npm。[E001], [E002]
- 服务器依赖 Python 以及已安装的 Python requirements。[E001], [E002]
- 该产品依赖通过 API/编辑器工作流提供显示定义和布局数据。[E002], [E005], [E006]

## 6. 数据需求

### 数据实体 / 对象
| 实体 | 已证实字段 | 说明 | 来源 |
|---|---|---|---|
| Gauge | `key`、`value` | `key` 是主键；在模型中 `value` 最大长度为 600。 | [E005], [E006] |
| Display | `key`、`available`、`resolution_x`、`resolution_y`、`current_layout`、`display_data`、`rotation` | `key` 是主键；`current_layout` 引用 `Layout` 且可为空。 | [E005], [E006] |
| Layout | `key`、`data`、`display_positions` | `key` 是主键；`data` 以二进制存储；`display_positions` 为文本。 | [E005], [E006] |

### 输入/输出数据
| 数据 | 方向 | 描述 | 来源 |
|---|---|---|---|
| Gauge 数据 | 输入/输出 | 由 `key` 和 `value` 标识的已提交和已获取数据项。 | [E002], [E005], [E006] |
| Display 注册数据 | 输入/输出 | 唯一显示键和显示分辨率值，以及状态字段。 | [E002], [E005], [E006] |
| Layout 数据 | 输入/输出 | 布局标识符、二进制 `data` 和 `display_positions`。 | [E005], [E006] |

### 存储、完整性、保留、隐私、迁移
| 主题 | 需求 / 观察 | 来源 |
|---|---|---|
| 存储 | 系统将 Gauge、Display 和 Layout 实体存储在持久化的服务器端模型中。 | [E006] |
| 引用完整性 | Display 可通过 `current_layout` 引用一个 Layout；如果该 Layout 被删除，则该引用被设为 null。 | [E006] |
| 隐私 / 保留 / 迁移 | 仓库证据不支持任何具体的隐私、保留或迁移需求。 | — |
