# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 定义了基于证据的软件需求，这些需求对应于提交 `99dae5686d1542aae88bc67a22370ec6c6a567a0` 时 `ae-prediction-cards` 仓库快照。该规格仅限于所提供仓库证据支持的行为和接口。

### 产品范围
该仓库包含：
- 一个预言机服务，定期检查预言机请求、对其进行应答，并检查是否有必要进行扩展。
- 一个前端 API 层，使用 Aeternity 钱包客户端与 prediction cards 智能合约接口交互，包括创建预测。
- 用于展示 HTTP CORS 处理和 Aeternity 交易领域集成的测试与部署工件。

### 目标读者
本文档适用于：
- 预言机服务和前端集成的维护者
- 验证仓库支持行为的测试工程师
- 使用前端 API 以及区块链/预言机环境进行集成的集成人员

### 参考资料
- 仓库：`kryptokrauts/ae-prediction-cards`
- 提交：`99dae5686d1542aae88bc67a22370ec6c6a567a0`
- 证据来源：`E001` 至 `E006`

## 2. 总体描述

### 产品视角
该产品是一个由多个组件组成的系统，包括：
- 基于 Quarkus 的预言机服务，带有计划调度的后台处理（`E001`）
- 绑定到 Aeternity 钱包的、基于 React 的前端 provider/API 层（`E003`, `E004`）
- 与 HTTP CORS 行为及 Aeternity 区块链交易类型相关联的测试基础设施（`E002`, `E005`, `E006`）

### 产品功能概述
仓库中有证据支持的功能包括：
- 定期检查预言机请求（`E001`）
- 响应预言机请求（`E001`）
- 定期检查是否需要扩展预言机（`E001`）
- 通过一个前端 API 方法创建预测记录，该方法通过交互式区块链实例提交事件和图像数据（`E004`）
- 通过 context 和钱包绑定向前端组件提供 prediction-cards API（`E003`）
- 使用定义的请求头接受浏览器跨源请求，支持 `GET`、`POST` 和 `OPTIONS`（`E002`）

### 用户类别
| 用户类别 | 描述 | 证据 |
|---|---|---|
| 带钱包的前端用户 | 用户通过已连接、由钱包支持的 API context 操作前端 | E003, E004 |
| 服务运维人员 | 负责运行具有强制环境配置的预言机服务的用户或运维人员 | E001 |
| 集成/测试运维人员 | 在测试基础设施中验证区块链和 HTTP 集成行为的用户 | E002, E005, E006 |

### 运行环境
| 环境方面 | 支持说明 | 证据 |
|---|---|---|
| 预言机运行时 | 预言机服务使用 Quarkus，并支持开发模式和打包执行 | E001 |
| 前端运行时 | 前端使用 React 和 Aeternity 钱包客户端/provider 模型 | E003, E004 |
| 区块链集成 | 系统与 Aeternity SDK 类型和服务集成 | E004, E005, E006 |
| HTTP 边界 | 存在用于浏览器风格跨源请求的 CORS 配置 | E002 |

## 3. 外部接口需求

### 用户接口
| 接口 | 需求摘要 | 证据 |
|---|---|---|
| 前端 API context | 前端应通过绑定到当前钱包的 context provider，向子组件暴露一个 prediction-cards API。 | E003 |
| 服务运行时接口 | 预言机服务应能够在开发模式和打包模式下运行，并支持基于环境的配置。 | E001 |

### 软件/API 接口
| 接口 | 需求摘要 | 证据 |
|---|---|---|
| 钱包接口 | 前端 prediction API 应使用钱包客户端作为其区块链交互的集成点。 | E003, E004 |
| 智能合约方法接口 | 前端 prediction API 应通过交互式实例调用名为 `create_prediction` 的合约方法。 | E004 |
| AENS 名称引用 | 前端 API 使用 AENS 名称 `predictioncards.chain`。 | E004 |
| Aeternity 服务/测试接口 | 测试基础设施使用 Aeternity 服务、交易、预言机和 AENS 领域模型。 | E005, E006 |

### 通信接口
| 接口 | 需求摘要 | 证据 |
|---|---|---|
| HTTP CORS | 跨源 HTTP 访问应允许 `GET`、`POST` 和 `OPTIONS` 方法。 | E002 |
| HTTP 头 | 跨源 HTTP 访问应允许并暴露已配置的请求/响应头，包括 `Content-Type`、`Cache-Control`、`Range` 以及配置中显示的相关头。 | E002 |

### 数据交换格式
| 格式/项目 | 支持说明 | 证据 |
|---|---|---|
| 预测创建输入 | 预测创建接受一个事件对象以及两个图像字符串值：`img_higher` 和 `img_lower`。 | E004 |
| 日期转换输入 | 预测创建会在提交合约前转换事件开始时间戳。 | E004 |
| 环境配置 | 预言机服务运行时配置通过 `.env` 属性提供。 | E001 |
