# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 定义了由证据支持的需求，这些需求适用于管理使用 Firebase 身份验证令牌进行本地会话建立与拆除的仓库组件，公开登录/登出 API 交互，并运行于包含 Firebase functions 和 OnFleet 的前端/后端架构中。

### 产品范围
根据现有证据，产品包括：
- 可独立启动的前端，
- 由 Firebase 无服务器函数和 OnFleet 任务处理组成的后端，
- 向内部 API 路由发送经过身份验证的登录和登出请求的会话处理，
- 由环境驱动的 Firebase 相关值配置。

本 SRS 仅限于由仓库证据直接支持的行为和约束。

### 预期读者
- 维护者和贡献者
- 测试人员
- 部署/配置操作人员
- 使用 Firebase 身份验证会话流的集成人员

## 2. 总体描述

### 产品视角
该仓库同时包含前端和后端元素。后端被描述为包含两部分：
- 用于部署自定义 API 的 Firebase functions
- 作为任务处理系统的 OnFleet

前端中的会话处理器与用于登录和登出的内部 API 端点进行通信。Firebase 相关环境变量被注入到应用程序配置中。

### 产品功能概述
- 从经过身份验证的用户获取 Firebase ID 令牌，并将其提交到内部登录 API。
- 当没有用户存在时，向内部登出 API 提交登出请求。
- 接受包含请求体中令牌的登录 API 请求。
- 在登录处理期间验证 Firebase ID 令牌。
- 从环境变量公开 Firebase 配置值。

### 用户类别
由证据支持：
- 已认证应用用户：通过 Firebase 身份验证会话流发起登录。
- 已登出或未认证用户：发起登出或没有活动用户对象。
- 开发者/操作人员：配置环境变量并启动前端和后端服务器。

### 运行环境
由证据支持：
- 前端服务器
- 后端服务器
- Firebase 无服务器函数
- OnFleet 集成
- 基于 Next.js 的配置环境，支持 CSS/Sass 和资源加载

### 假设与依赖
- 登录流程依赖于能够从用户对象获取 Firebase 身份验证令牌。(`E001`)
- 后端依赖 Firebase functions 提供自定义 API，以及依赖 OnFleet 进行任务处理。(`E002`, `E004`)
- Firebase 配置依赖于环境变量存在于项目根配置设置中。(`E002`, `E006`)

## 3. 外部接口需求

### 用户接口
证据中未明确描述直接面向最终用户的 UI 行为。所支持的面向用户交互仅限于由应用程序逻辑触发的、由身份验证驱动的会话建立和登出请求。

### 软件/API 接口
| 接口 | 描述 | 证据 |
|---|---|---|
| `POST /api/login` | 接受包含 `token` 值的 JSON 请求；在获取 Firebase ID 令牌后由会话处理器使用。 | `E001`, `E003`, `E005` |
| `POST /api/logout` | 接受来自会话处理器的登出请求，并使用同源凭据。 | `E001`, `E003` |
| Firebase 令牌验证 | 登录处理使用 Firebase 令牌验证。 | `E005` |
| OnFleet 后端集成 | 后端包含作为任务处理系统的 OnFleet。 | `E002`, `E004` |

### 通信接口
| 接口方面 | 需求支持的细节 | 证据 |
|---|---|---|
| HTTP 方法 | 登录和登出请求使用 `POST`。 | `E001`, `E003` |
| 内容类型 | 登录请求发送 `Content-Type: application/json`。 | `E001`, `E003` |
| 凭据模式 | 登录和登出请求使用 `credentials: "same-origin"`。 | `E001`, `E003` |

### 数据交换格式
| 交换 | 格式 | 证据 |
|---|---|---|
| 登录请求体 | 包含 `token` 的 JSON 对象 | `E001`, `E003`, `E005` |
| 登出请求体 | 证据中未显示请求体 | `E001`, `E003` |
| 配置值 | 映射到应用程序配置中的环境变量 | `E006` |
