## 1. 引言

### 1.1 目的
本 SRS 定义了基于 `nasa/cFS` 可用 README 和 GitHub 工作流材料所证明的仓库特定需求。范围仅限于已记录的构建/测试工作流、已记录的遥测交互，以及已识别的外部集成点。

### 1.2 产品范围
根据证据，本仓库提供：
- 使用 `make` 的 cFS 构建和测试工作流
- 一个可运行的 cFS 目标可执行文件（`core-cpu1`），用于功能测试
- 一个主机端命令工具（`cmdUtil`），用于发送命令
- 可针对指定 IP 地址启用的遥测交互
- 已记录的相关接口、库和工具

### 1.3 预期读者
- 从此仓库构建或测试 cFS 的集成人员
- 执行遥测和命令路径操作的操作员或测试人员
- 审查仓库验收标准的维护者
- 使用仓库工作流的工具/CI 工程师

### 1.4 参考资料

- GitHub 工作流 `.github/workflows/build-cfs-deprecated.yml` — 证据 ID：E002, E006

## 2. 总体描述

### 2.1 产品视角
证据表明，该仓库是一个可构建且可测试的 cFS 代码库，并集成了 GitHub Actions 工作流。它支持本地或 CI 驱动的执行、主机到目标的命令交互以及遥测观测。

### 2.2 产品功能概述
- 使用示例 make 资源准备并安装 cFS 构建
- 针对正在运行的 `core-cpu1` 执行功能测试
- 允许向配置的 IP 地址启用遥测
- 允许发送诸如 no-op 之类的命令并观察命令计数器递增
- 根据仓库历史/问题元数据生成分类的变更日志工件

### 2.3 用户类别
- 开发者/构建用户
- CI 操作员/维护者
- 功能测试人员
- 遥测/地面测试用户

### 2.4 运行环境
证据支持以下环境：
- 运行于 `ubuntu-latest` 和 `ubuntu-18.04` 的 GitHub Actions runner（E001, E005, E006）
- 构建变体：`debug` 和 `release`（E002, E006）
- 网络化执行环境，用户可输入执行 cFS 的系统 IP 地址，包括用于本地执行的 `127.0.0.1`（E004）

### 2.5 假设与依赖
- 源代码检出包含 Git 子模块（E002）
- 构建准备依赖于提供的 `Makefile.sample` 和 `sample_defs` 资源（E002）
- 功能测试依赖于 `core-cpu1` 和 `../host/cmdUtil` 的存在（E006）
- 已记录相关外部元素，包括 SIL、ECI、`cFS_IO_LIB`、`cFS_LIB`、CCDD、Perfutils-java 和 `gen_sch_tbl`（E003）

## 3. 外部接口需求

### 3.1 用户接口
| 接口 | 需求 | 证据 |
|---|---|---|
| 遥测启用 UI | 系统文档应支持一种用户流程，在该流程中启用遥测并输入执行 cFS 的系统 IP 地址，包括用于本地执行的 `127.0.0.1`。 | E004 |

### 3.2 软件/API 接口
| 接口 | 需求 | 证据 |
|---|---|---|
| 构建接口 | 仓库应支持通过 `make prep` 和 `make install` 进行构建准备和安装。 | E002 |
| 主机命令接口 | 仓库应支持使用带有数据包和命令参数的 `cmdUtil` 进行主机端命令传输。 | E006 |
| 外部相关接口 | 仓库应记录相关接口/库/工具，包括 SIL、ECI、`cFS_IO_LIB`、`cFS_LIB`、CCDD、Perfutils-java 和 `gen_sch_tbl`。 | E003 |

### 3.3 通信接口
| 接口 | 需求 | 证据 |
|---|---|---|
| 基于 IP 的遥测 | 系统应接受一个已配置的 IP 地址，用于连接到执行 cFS 的系统以进行遥测。 | E004 |
| 命令路径 | 系统应在功能测试期间接受来自主机工具的命令数据包。 | E006 |

### 3.4 数据交换格式
| 格式 | 需求 | 证据 |
|---|---|---|
| 命令行命令数据包字段 | 主机命令接口应接受包括 `pktid`、`cmdcode`、`endian` 和 `uint32` 值在内的参数。 | E006 |
| 变更日志分段 | 生成的变更日志内容应在带标签的分段下对条目进行分类，包括 closed issues、breaking changes、enhancements、bugs、deprecated items、removed items 和 security fixes。 | E001 |
