## 2. 总体描述

### 产品视角
证据显示 psmpi 是一个面向通信的软件栈，具有：
- 使用面向 VC 的进度和连接操作的通信子系统，
- 具有流量控制以及直接/打包数据处理的基于分组的发送行为，
- 通过 Linux Verbs API 对 Libfabric verbs 支持的可选集成，
- 手动执行的嵌入式 `hwloc` 验证工作流。

### 产品功能概述
- 针对发行版 tarball 运行嵌入式 `hwloc` 验证
- 支持嵌入式 `hwloc` 的手动构建和测试工作流
- 提供通信生命周期和进度操作
- 支持一对多传输/散播行为
- 在提交数据发送前应用流量控制
- 通过直接访问固定的用户数据或通过数据包缓冲区打包来发送数据
- 通过 `libibverbs` 和 `librdmacm` 集成 verbs 传输

### 用户类别
- 手动运行嵌入式 `hwloc` 测试的开发者/测试人员（`E001`, `E002`）
- 使用外部库构建启用 verbs 的传输的集成人员（`E003`）
- 使用 progress/connect/scatter 接口的通信子系统集成人员（`E004`）

### 运行环境
证据支持：
- 通过 shell 环境使用脚本和 autotools 风格命令（如 `./autogen.sh`、`./configure` 和 `make`）执行构建/测试（`E001`, `E002`）
- 使用 Linux Verbs API 并结合 `libibverbs` 和 `librdmacm` 的 verbs 传输集成（`E003`）

### 假设与依赖
- Verbs provider 支持依赖于 `libibverbs` 版本 `1.1.8` 或更新版本，以及 `librdmacm` 版本 `1.0.16` 或更新版本（`E003`）
- 从源代码编译带 verbs 支持的 Libfabric 时需要匹配的头文件（`E003`）
- 非默认库/头文件位置必须通过 `CFLAGS`、`LDFLAGS` 和 `LD_LIBRARY_PATH` 提供（`E003`）
- 嵌入式 `hwloc` 测试是手动的，不属于 `make check` 的一部分（`E001`, `E002`）

## 3. 外部接口需求

### 用户接口
- 通过 `./run-embedded-tests.sh <tarball>` 执行嵌入式测试的命令行/脚本接口（`E001`, `E002`）
- 通过 `./autogen.sh`、`./configure` 和 `make` 进行手动嵌入式验证的命令行构建接口（`E001`, `E002`）

### 软件/API 接口
- 到 Linux Verbs API 的 verbs provider 接口（`E003`）
- 通过 `librdmacm` 进行通信管理，并通过 `libibverbs` 进行控制/数据传输（`E003`）
- 通信子系统操作：
  - `Init()`
  - `Finalize()`
  - `Make_progress(VC)`
  - `Make_progress_blocking()`
  - `Connect(VC, rank, comm or BNR_Group, &request)` (`E004`)

### 通信接口
- 在通信说明中识别出一对多的散播式传输接口（`E004`）
- 分组发送与网络设备和网络发送描述符交互（`E005`, `E006`）

### 数据交换格式
支持的消息/数据形式包括：
- 对于 `rndv-rts`，承载 envelope 和 `LIBA(OD)` 的数据包缓冲区内容，
- 对于 `rndv-cts`，两个 `LIBAs`，
- 对于 `rndv-data`，一个 `LIBA`，
- 当不使用直接访问时，从数据描述符打包到数据包缓冲区中的负载数据（`E006`）
