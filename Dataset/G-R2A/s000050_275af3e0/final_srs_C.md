# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 定义了针对仓库快照 `SafeBreach-Labs/hAFL2`（提交 `64e1bfab4a63a3515fcbbbfce2a5837a2c71bafa`）的、由证据支持的需求。证据所支持的范围是该仓库在以下方面的模糊测试支持工作流：
- `kAFL-Fuzzer` 测试执行
- Linux 用户态模糊测试启动脚本
- Windows 模糊测试辅助二进制文件和设置步骤

### 产品范围
根据证据，该仓库提供：
- 用于运行 `kAFL-Fuzzer` 测试套件的独立入口点
- 通过 `initrd` 在 kAFL 中启动 Linux 用户态二进制文件的示例脚本
- 一个将 kAFL hypercall 映射到 AFL 风格客户机 I/O 的嵌入式 forkserver
- 面向 Windows 目标的模糊测试二进制文件，以及涉及 harness 和崩溃监控驱动程序的设置工作流

### 目标读者
- 使用 kAFL/hAFL2 工作流的模糊测试操作人员
- 维护测试和启动工作流的开发人员
- 准备 Linux 用户态或 Windows VM 模糊测试环境的集成人员

### 参考资料
- 仓库：https://github.com/SafeBreach-Labs/hAFL2
- 快照：https://github.com/SafeBreach-Labs/hAFL2/tree/64e1bfab4a63a3515fcbbbfce2a5837a2c71bafa
- 证据来源：`kAFL-Fuzzer/test.py`, `tests/user_bench/README.md`, `tutorial.md`, `kAFL-Fuzzer/tests/test_deterministic.py`

## 2. 总体描述

### 产品视角
有证据支持的组件是一个模糊测试支持工具集，而不是一个独立的终端用户应用程序。它包括测试运行工具、Linux 用户态启动脚本以及面向 Windows 目标的构建/设置工件。

### 产品功能概述
- 从独立脚本执行常规 `kAFL-Fuzzer` 测试套件。
- 通过将选定的 Linux 用户态二进制文件打包到 `initrd` 中来启动它们。
- 使用嵌入式 forkserver 在客户机内将 kAFL hypercall 转换为 AFL 风格 I/O。
- 将所需的共享库从主机复制到 `initrd` 中。
- 提供 Windows 辅助二进制文件，其中 `packet_sender.exe` 触发发送数据包的 IOCTL，而 `loader.exe` 创建模糊测试快照、加载并执行 `packet_sender.exe`。

### 用户类别
- 运行或扩展 `kAFL-Fuzzer` 测试的开发人员
- 启动 Linux 用户态目标的模糊测试用户
- 准备 harness、驱动程序和 VM 配置的 Windows 模糊测试操作人员

### 运行环境
- Python 3 用于独立测试入口点。`pytest` 用于执行常规测试。`bash` 用于编译模糊测试二进制文件。证据还提到了 Visual Studio、IDA Pro、提升权限的 Windows 命令提示符，以及子/root 分区 VM。  
来源：`E001`, `E003`, `E004`

### 假设与依赖
- Linux 用户态模糊测试假定目标二进制文件可以被打包到 `initrd` 中。  
来源：`E002`
- 目标所需的共享库在主机上可用，以便复制到 `initrd` 中。  
来源：`E002`
- Windows 设置依赖于编译辅助二进制文件和驱动程序，以及依赖于 Windows 构建特定的偏移配置。  
来源：`E003`, `E004`

## 3. 外部接口需求

### 用户接口
- 支持通过命令行执行独立测试运行器以及模糊测试/构建脚本。  
来源：`E001`, `E003`

### 软件/API 接口
- Linux 用户态模糊测试通过嵌入式 forkserver 与客户机执行进行交互，该 forkserver 将 kAFL hypercall 映射为 AFL 风格 I/O。  
来源：`E002`
- Windows 模糊测试辅助程序与发送数据包的 IOCTL 和模糊测试快照加载器工作流进行交互。  
来源：`E003`

### 通信接口
- 在 Windows 工作流中，`packet_sender.exe` 通过一个 IOCTL 触发数据包发送。  
来源：`E003`

### 数据交换格式
- Linux 启动工作流会构造一个包含所选目标二进制文件和所需共享库的 `initrd`。  
来源：`E002`
- 确定性变异测试对可变字节负载和可选的 effector map 进行操作。  
来源：`E005`, `E006`
