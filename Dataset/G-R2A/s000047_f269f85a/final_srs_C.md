# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 定义了针对提交 `a93230c0fa557fc0652703bdf2d105788b453aa8` 时仓库组件的、基于证据支撑的需求，重点关注持久化用户设置、哈希计算以及由现有证据支持的导出生成工作流。

### 产品范围
此处有证据支撑的产品范围包括：
- 对持久化用户设置进行清理，
- 异步生成树形 CSV、CSV、Excel 和 RESIP 导出，
- 带有调试输出文件的批量哈希计算，
- 将语言设置传播到导出生成工作流中。

### 预期读者
本文档面向从事有证据支撑的仓库行为相关工作的维护人员、测试人员、集成人员和审查人员。

## 2. 总体描述

### 产品视角
有证据支撑的产品行为被组织为控制器级别的工作流，这些工作流会调用后台 worker 进程来执行导出和哈希相关操作。它还包括与用户设置相关的持久化清理。`E001 E002 E003 E004 E005 E006`

### 产品功能概述
- 清理持久化用户设置，并在输入为空、未定义或无效时应用默认值。`E001`
- 异步生成树形 CSV 导出。`E002`
- 异步生成带有进度/结果处理的 RESIP 导出。`E003`
- 分批计算哈希，并在应用程序用户数据目录下写入调试输出。`E004`
- 从文件、元数据、别名、注释、标签和哈希生成 CSV 导出。`E005`
- 从与 CSV 导出兼容的数据生成 Excel 导出。`E006`

### 用户类别
- 其偏好被持久化为设置以用于跟踪、监控和语言的终端用户。`E001`
- 使用仓库提供的接口触发导出和哈希生成工作流的操作人员或集成人员。`E002 E003 E004 E005 E006`

### 运行环境
- 具有对 Electron `remote.app.getPath("userData")` 访问能力的桌面应用程序运行时。`E004`
- 支持后台 worker 处理和基于 observable 的结果交付的执行环境。`E002 E003 E005 E006`

### 假设与依赖
- 导出生成依赖于翻译子系统中的当前语言值。`E002 E003 E005 E006`
- 哈希计算依赖于文件系统路径和应用程序特定的用户数据目录。`E004`

## 3. 外部接口需求

### 用户接口
所提供材料中没有直接的用户界面行为证据。

### 软件/API 接口
| 接口 | 描述 | 证据 |
|---|---|---|
| 用户设置清理 | 接受持久化设置输入，并在需要时返回带有默认值的规范化设置。 | E001 |
| 树形 CSV 导出生成 | 接受文件与文件夹映射，并返回异步导出进度/结果。 | E002 |
| RESIP 导出生成 | 接受文件、元数据、别名、注释和标签，并返回异步进度/结果。 | E003 |
| 哈希计算 | 接受文件路径和基础路径选项，并在写入调试输出的同时返回数据处理流。 | E004 |
| CSV 导出生成 | 接受别名、注释、文件、元数据、标签、哈希以及依赖语言的上下文用于导出生成。 | E005 |
| Excel 导出生成 | 接受与 CSV 导出兼容的数据，并返回异步导出结果。 | E006 |

### 通信接口
| 接口 | 需求 | 证据 |
|---|---|---|
| 后台 worker 调用 | 导出和哈希工作流应使用后台 worker 或批处理机制，而不是仅使用直接同步计算。 | E002 E003 E004 E005 E006 |
| Observable/数据流交付 | 树形 CSV、RESIP 以及 Excel/CSV 相关工作流应通过 observable 或类流接口暴露异步结果。 | E002 E003 E004 E006 |

### 数据交换格式
| 格式 | 用途 | 证据 |
|---|---|---|
| CSV 文本 | 树形导出和 CSV 导出输出。 | E002 E005 |
| Excel 导出数据 | 从与 CSV 导出兼容的输入数据生成的 Excel 导出。 | E006 |
| RESIP 导出数据 | RESIP 导出工作流输出。 | E003 |
| 哈希映射 | 批量哈希计算结果聚合。 | E004 |
