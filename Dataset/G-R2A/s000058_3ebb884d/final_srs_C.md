# 软件需求规格说明书

## 1. 引言

### 目的
本 SRS 定义了针对提交 `6f5047f26d6ee51450baa17a614ac671cb3a7224` 的 `macpro-appian-connector` 仓库的、由证据支持的需求。其涵盖证据包直接支持的仓库行为：连接器配置、AWS 阶段列表、告警路由以及部署指标收集。

### 产品范围
该仓库提供基于 AWS 的运维能力，用于：
- 列出当前 AWS 账户中当前正在运行的阶段，
- 为目标服务配置并重启连接器定义，
- 通过 EventBridge 将匹配的服务事件路由到 SNS，
- 从 GitHub 收集部署和拉取请求指标。

### 目标读者
本文档适用于：
- 正在熟悉或扩展该仓库的开发人员，
- 在 AWS 中运行仓库工作流的运维人员，
- 根据仓库证据验证行为的审查人员。

## 2. 总体描述

### 产品视角
该产品是一个与 AWS 集成的服务与运维仓库。证据显示其与 AWS ECS 相关连接器操作、EventBridge、SNS、基于 AWS CLI 的阶段操作，以及基于 GitHub Actions 和 GitHub API 的报告功能集成。

### 产品功能概述
该仓库支持以下功能：
- 列出当前 AWS 账户中项目当前正在运行的阶段，
- 将连接器配置变更应用到目标集群和服务，并重启受影响的连接器，
- 将来自 EventBridge 规则的匹配事件路由到 SNS 主题，
- 将 SNS 订阅管理保持在部署自动化之外，
- 从 GitHub Actions 工作流运行中计算某分支的部署成功/失败次数，
- 计算某分支的拉取请求平均合并时间。

### 用户类别
- 开发人员：执行入门配置、运行阶段列表脚本并使用仓库工作流。
- 运维/DevOps 用户：提供 AWS 凭证、运行以 AWS 账户为范围的操作并观察告警。
- 仓库维护者：管理连接器定义和部署指标。
- 通知管理员：手动添加或移除 SNS 订阅。

### 运行环境
支持的环境证据包括：
- 具有可用 AWS CLI 凭证的 AWS 账户（`E001`），
- 入门配置和脚本使用期间基于终端的本地执行（`E002`, `E001`），
- 作为 CI/CD 工具的 GitHub Actions（`E001`），
- 用于告警路由的 AWS EventBridge 和 SNS（`E003`），
- 用于工作流和拉取请求指标的 GitHub API 访问（`E005`, `E006`）。

### 假设与依赖
- 用户在运行阶段列表流程前已完成入门配置（`E001`）。
- 在执行 AWS 阶段列表操作前，必须获取并设置 AWS CLI 凭证（`E001`）。
- 连接器操作依赖于已配置的 `cluster` 和 `service` 环境值以及已定义的连接器集合（`E004`）。
- 部署指标依赖于可通过 GitHub API 分页获取的 GitHub 工作流运行和拉取请求数据（`E005`, `E006`）。

## 3. 外部接口需求

### 用户接口
| 接口 | 需求 |
|---|---|
| 终端/脚本接口 | 系统应支持一种基于运行脚本的流程，在完成入门配置并设置 AWS 凭证后列出当前正在运行的阶段。来源：`E001` |
| 手动订阅管理 | SNS 订阅成员资格应通过手动方式管理，而不是通过部署进行管理。来源：`E003` |

### 软件/API 接口
| 接口 | 需求 |
|---|---|
| AWS CLI | 阶段列表操作应依赖于在当前环境中设置 AWS CLI 凭证。来源：`E001` |
| AWS EventBridge | 系统应通过使用事件过滤条件定义的 EventBridge 规则接收匹配事件。来源：`E003` |
| AWS SNS | 系统应将由 EventBridge 触发的匹配事件发布到被授权可供 EventBridge 调用的 SNS 主题。来源：`E003` |
| 连接器管理库 | 连接器配置应为目标集群和服务调用连接器创建、删除和重启操作。来源：`E004` |
| GitHub Actions API | 部署指标应查询 `deploy.yml` 的工作流运行。来源：`E005` |
| GitHub Pull Requests API | 拉取请求指标应查询指定基础分支的已关闭拉取请求。来源：`E006` |

### 通信接口
| 接口 | 需求 |
|---|---|
| 事件传递 | 当规则模式匹配时，匹配事件应从 EventBridge 流向 SNS。来源：`E003` |
| GitHub API 分页 | 指标收集应聚合分页的 GitHub API 响应。来源：`E005`, `E006` |

### 数据交换格式
| 格式 | 需求 |
|---|---|
| 工作流运行记录 | 部署指标应使用包含 `conclusion` 字段的工作流运行记录。来源：`E005` |
| 拉取请求记录 | PR 指标应使用包含 `created_at`、`merged_at` 和 `base` 分支过滤输入的拉取请求记录。来源：`E006` |
| 指标输出 | 部署指标应输出 `failedRuns` 和 `passedRuns`；PR 指标应输出 `averageTimeToMerge`。来源：`E005`, `E006` |
| 连接器配置数据 | 连接器操作应使用连接器集合以及 `cluster` 和 `service` 值。来源：`E004` |
