﻿# Smart Recipe System Software Requirements Specification (Standard SRS Extract)

## 1. Introduction

### Purpose
Its purpose is to provide structured input for architecture generation, test design, and requirements traceability for a deep-learning-based smart recipe system.

### Product Scope

The Smart Recipe System is a deep-learning-based photo recipe generation app. It allows users to recognize food by taking photos, generate ingredient lists and cooking steps, and obtain calorie judgment, food-combination taboo checks, nutrition analysis, diet plans, daily check-ins, community sharing, and personalized recommendations. The specification states that the system is an Android application, while the non-functional requirements require the foreground interface to be usable on common mobile terminals such as Android and iOS devices.

### Intended Audience

This document is intended for general users, health-conscious users, food-making users, food critics, catering companies, system administrators, developers, testers, and downstream architecture generation workflows. Administrators are responsible for daily operations and maintenance, upgrades, fault handling, user management, recipe database management, user feedback handling, and review of user-published data.

## 2. Overall Description

### Product Perspective

The system includes a mobile app interface and backend services. The app communicates with the backend service layer through Ajax interaction and direct interaction. The backend service layer includes the business layer, control layer, service layer, and data access layer, and is built with Spring Boot and Flask. Spring Boot handles the main business logic, while Flask provides the model inference service. The backend uses MySQL to store structured data and Redis to cache data for improved performance.

### Product Functions Summary

| Capability | Summary |
| --- | --- |
| Personal information | Manage user information, implement account registration and login, and allow administrators to manage accounts in batches. |
| Photo-based recipe recognition | Preprocess food photos, perform validity checks and model inference, and return recipe information or error messages. |
| Text-based recipe search | Compare user search text with recipe data in the database and return results sorted by relevance. |
| Health analysis | Combine recipes, nutrition data, and user health data to provide nutrition analysis, diet advice, diet plans, and daily check-ins. |
| Community sharing | Support users uploading recipe text and images, administrator review before publication, push to other users, likes, comments, and merchant location display. |
| Intelligent recommendation | Recommend recipes based on query history, browsing data, follows, recipe analysis history, and sharing records. |
| Administrator management | Allow administrators to add recipes, review user recipes, and maintain users and the recipe database. |
